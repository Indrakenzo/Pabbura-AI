Pabbura-AI 🩺

Pabbura (Bahasa Bugis: Pengobatan). 
Pabbura-AI adalah antarmuka asisten kesehatan virtual berbasis web 3D yang menggunakan API gratis dari OpenRouter.

Fitur
- Desain 3D Glassmorphism & Responsif.
- Mascot Robot Chibi Medis interaktif.
- Pilihan puluhan model AI gratis OpenRouter.
- Disiapkan untuk integrasi Vercel Serverless Function.
